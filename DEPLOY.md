# Как выложить Pyramid в интернет за 10 минут

Ничего устанавливать не нужно. Всё делается в браузере. В конце у вас будет
адрес вида `https://pyramid-xxxx.onrender.com`, который можно открыть с любого
устройства и отправить второму человеку.

Понадобятся два бесплатных аккаунта: GitHub (хранилище кода) и Render
(запуск). Карта не нужна ни там, ни там.

---

## Шаг 1. Положить код на GitHub

1. Зайдите на **github.com**, зарегистрируйтесь или войдите.
2. Нажмите **+** в правом верхнем углу → **New repository**.
3. Имя: `pyramid`. Тип: **Public**. Нажмите **Create repository**.
4. На странице пустого репозитория нажмите ссылку **uploading an existing file**.
5. Распакуйте архив `pyramid.zip` у себя на устройстве и **перетащите в окно
   браузера содержимое папки** `pyramid` — то есть файлы `server.js`,
   `package.json`, `package-lock.json`, `render.yaml`, `README.md` и папку
   `public` целиком. В папке `public` должно быть пять файлов: `index.html`,
   `app.js`, `i18n.js`, `day.js`, `scene.js`.
6. Внизу нажмите **Commit changes**.

Проверьте, что в репозитории видно `server.js` и папку `public` с двумя
файлами внутри. Папку `tracks` загружать не нужно, сервер создаст её сам.

## Шаг 2. Запустить на Render

1. Зайдите на **render.com** → **Get Started** → войдите через GitHub.
2. В панели нажмите **New** → **Web Service**.
3. Выберите свой репозиторий `pyramid`. Если его не видно, нажмите
   **Configure account** и дайте Render доступ к нему.
4. Render сам подставит настройки из файла `render.yaml`. Проверьте, что стоит:
   - Language / Runtime: **Node**
   - Build Command: `npm install`
   - Start Command: `node server.js`
   - Instance Type: **Free**
5. Нажмите **Deploy Web Service** и подождите две-три минуты. В журнале
   должно появиться `Pyramid слушает`.

Готово. Наверху страницы будет ваш адрес.

## Шаг 3. Проверить

1. Откройте адрес на телефоне. Введите имя, нажмите **Войти в комнату**,
   разрешите доступ к микрофону.
2. Нажмите **Пригласить** — ссылка скопируется. Отправьте её второму человеку
   или откройте на втором своём устройстве.
3. Наденьте наушники хотя бы на одной стороне, иначе будет вой.
4. Выберите пластинку. Музыка должна пойти у обоих одновременно.
5. Смотрите в блок **«Что происходит внутри»** — там расхождение музыки,
   задержка голоса и состояние связи.

## Что важно знать про бесплатный тариф

**Сервис засыпает через 15 минут без обращений.** Первый вход после сна ждёт
около минуты — страница покажет «сервер просыпается». Это нормально для
бесплатного тарифа и лечится только платным.

**Загруженные треки пропадают** при перезапуске сервиса: файловая система там
временная. Демо-треки создаются заново при каждом старте, они никуда не денутся.

**Микрофон заработает сразу**, потому что Render выдаёт HTTPS. Локально по
обычному адресу браузер микрофон бы не дал.

## Шаг 4: TURN — без него телефоны в разных сетях друг друга не услышат

Голос идёт напрямую между устройствами. Если оба в одной сети — всё работает
и так. Но айфон на мобильном интернете и андроид дома почти никогда не могут
соединиться напрямую: операторы прячут телефоны за общим адресом. Чат и музыка
при этом работают, потому что идут через сервер, — ровно так было у вас.

TURN — ретранслятор, который пересылает звук, когда прямой путь закрыт.
Бесплатно: Open Relay от Metered, 20 ГБ в месяц. Голос весит около 40 килобит
в секунду, так что этого хватит примерно на пятьсот часов разговоров через
ретранслятор, а через него пойдут только звонки, не соединившиеся напрямую.

1. Зайдите на **metered.ca**, раздел Open Relay / TURN Server, зарегистрируйтесь
   бесплатно.
2. В панели найдите две вещи: **имя приложения** — это часть адреса вида
   `ваше-имя.metered.live` — и **API-ключ** для получения TURN-паролей.
3. На **render.com** откройте свой сервис → **Environment** → **Add Environment
   Variable** и добавьте две переменные:
   - `METERED_APP` — имя приложения, без `.metered.live`
   - `METERED_KEY` — API-ключ
4. Нажмите **Save**. Render перезапустит сервис сам.
5. Проверьте: в журнале Render должна появиться строка «TURN настроен», а в
   комнате, в диагностике по кнопке «i», строка «ретранслятор» — «включён».

Ключ хранится только на сервере и в браузер не попадает.

Если в панели Metered вместо ключа вам показали готовые адрес, логин и пароль,
задайте вместо этого три переменные: `TURN_URL`, `TURN_USER`, `TURN_PASS`.
Адресов может быть несколько через запятую.

## Как понять, что со связью

В комнате нажмите кнопку «i». Строка **«вывод»** говорит простыми словами:

- **«голос идёт»** — всё в порядке;
- **«коснитесь экрана»** — айфон придержал звук, одно касание его отпустит;
- **«прямого пути нет: нужен ретранслятор TURN»** — настройте шаг 4;
- **«не помог даже ретранслятор»** — неверные ключи TURN.

## Если что-то пошло не так

**Сборка упала** — откройте вкладку **Logs** в Render, там будет причина.
Чаще всего это неполная загрузка файлов на шаге 1.

**Открывается, но «связь потеряна»** — подождите минуту, сервис просыпается.

**Не просит микрофон** — проверьте, что адрес начинается с `https://`.

**Слышно эхо или вой** — кто-то без наушников. Нажмите кнопку
«Я на динамике» / «Я в наушниках» соответственно своей ситуации.

**Голос не поднялся** — смотрите строку «вывод» в диагностике, раздел выше.
